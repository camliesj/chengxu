# 智纬可见名称替换设计

## 目标

将产品的所有用户可见名称从“智维车服”统一改为“智纬”，不影响既有安装、数据、登录和服务端兼容性。

## 选定方案

采用仅替换可见名称的方案：网页、Windows 客户端和 Android 的标题、应用名称、登录文案及发布说明使用“智纬”。现有图标继续使用，不重新设计视觉资产。

## 保持不变的技术边界

- Android 包名、签名身份、数据库名和 Room/D1 结构保持不变。
- Cloudflare Pages 项目、API 路径、认证会话键与 COS 对象键保持不变。
- 已发布 Android APK 的下载地址和文件名 `zhiwei-car-service_0.1.0.apk` 保持不变，避免已生成的二维码和安装链接失效。
- Windows 客户端的技术标识 `com.chengxu.*` 与更新通道保持不变。

## 变更范围

- Web：浏览器标题、登录页和应用内品牌文字。
- Windows：Tauri 产品名及窗口标题（共享 Web 登录页同步生效）。
- Android：启动器名称、应用身份、登录页标题和可见提示文字。
- 文档：交接记录和品牌规格中的当前产品名称说明。

## 验收标准

- 三端可见产品名均为“智纬”。
- 现有 Android 下载 URL 与二维码数据不变且仍可用。
- Node 测试、Web 构建、Android JVM/编译/lint/APK 构建通过；新 APK 保持可安装且 v2 签名有效。
- 不创建 D1 或 Room migration，不修改业务数据。
