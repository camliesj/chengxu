# 智维车服跨端品牌设计

## 目标

为网页、Windows 客户端与 Android 客户端建立统一、简洁且专业的产品名称和应用图标。

## 名称

- 正式中文名：**智维车服**
- 使用范围：网页标题、Windows 应用名称、Android 应用名称、登录页及产品下载入口。
- 名称含义：`智` 表示数字化协同，`维` 表示维修维护，`车服`明确汽车服务行业与业务边界。

## 图标方向

- 画布：正方形应用图标，适合 Android 启动图标、网页 favicon 与 Windows 图标。
- 背景：深石墨色圆角方形，匹配现有克制、专业的界面基调。
- 图形：中央抽象 `W` 结构，兼具“维”的识别和两条服务道路/车辆前脸的联想。
- 点缀：冰蓝色作为唯一强调色，表现智能、可信和协同。
- 约束：不含中文或英文文字；小尺寸下仍能清晰识别；不使用渐变、拟物阴影、维修工具或复杂车辆插画。

## 交付物

1. 一张 1024×1024 的高质量图标预览图。
2. 用户确认图标后，再生成适配 Android、网页和 Windows 的项目内资源，并分别替换三端显示名称。

## 非目标

- 本阶段不修改现有业务功能、数据库、接口或权限。
- 未经用户对预览图确认，不替换三端现有资源和应用名称。
