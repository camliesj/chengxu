# 智纬跨端登录统一、客户端下载收纳与背景元素设计

## 目标

消除网页端与 Windows 客户端登录页的视觉差异，将 Android 二维码从登录表单外部移入“客户端下载”弹窗，并为两端登录页增加同一张低干扰品牌背景元素图。

## 已确认的产品决定

- 网页与 Windows 客户端共用同一 `AccessGate` 登录组件、品牌名“智纬”、说明文案、表单节奏、主按钮和客户端下载入口。
- 登录表单下方仅保留紧凑的“客户端下载”按钮；二维码不在登录页默认露出，不占用表单纵向空间。
- “客户端下载”弹窗展示 Windows 与 Android 两张对齐的下载卡：Windows 提供版本、说明和下载按钮；Android 在卡片内部提供二维码、版本、大小、更新说明和备用下载按钮。
- 登录背景使用一张新生成的浅冰蓝抽象插画：车辆轮廓、维修轨迹与柔和几何线条；无文字、无 Logo、无人物、无真实照片。它位于视口右侧与底部，低对比度，不影响表单可读性。
- 小屏幕弱化背景，下载弹窗改为单列，二维码完整保留在 Android 卡片内。

## 结构与交互

1. `AccessGate` 只承担登录和打开下载弹窗；移除其外部 `AndroidInstallQr` 区块。
2. `ClientDownloadsDialog` 成为唯一的下载信息承载区，并读取现有 `/api/client-releases` 元数据。未发布 Android 包时，不生成二维码，明确显示发布中状态。
3. Android 下载卡仅在 HTTPS 下载地址可用时展示本地二维码和“下载 Android APP”按钮；二维码和按钮使用同一 URL。
4. 新背景图作为 `public/brand/` 的静态资产，通过 CSS background image 应用于登录容器；表单卡和弹窗保持实色表面及可见焦点状态。

## 视觉规范

- 页面背景：冷白与极浅冰蓝；背景图透明度/混合强度应低于表单与正文层级。
- 表单卡：约 520px 宽，白色表面、细冰蓝描边、深海军蓝标题；主按钮沿用当前行动蓝。
- 下载入口：登录主按钮下方的次级文本按钮，不与“进入系统”竞争。
- 下载弹窗：大屏双列卡片，小屏单列；Android 二维码置于独立浅色方形区域，旁边为信息与下载操作，禁止溢出卡片。
- Windows 窗口标题和产品可见文案统一为“智纬”，不改变包名、API、认证、D1/Room schema 或发布接口合同。

## 验证与非目标

- 新增/更新前端逻辑测试，确保二维码只存在于下载弹窗、只编码可用 HTTPS Android URL，网页与桌面复用同一登录组件。
- 执行 Node 测试、Vite build 与 Tauri 配置检查；不启动 Android 模拟器，不改变 Android 客户端业务功能。
- 本包不部署 Pages、不修改远端 D1、不会改变订单、档案、权限或会话数据。
