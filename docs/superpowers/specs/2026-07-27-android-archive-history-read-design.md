# Android 档案中心第一批：已结算历史工单只读设计

日期：2026-07-27
状态：已批准
范围：完整业务能力阶段 4 的第一批，仅交付 Android 已结算历史工单档案查询

## 1. 目标与范围

Android 的“档案”根标签目前是阶段占位页。本批将其替换为当前登录企业的真实已结算工单档案中心，使员工和管理员都能安全地查询历史、筛选、分页加载并进入已有的只读详情页。

本批只处理已结算工单的读取链路，不实现客户车辆、保险档案、管理员档案字段修正、结算、返结算、作废、回执或导出。所有档案操作保持只读；任何角色都不能在本批通过 Android 写入历史工单。

## 2. 已确认的架构

### 2.1 单一历史读取契约

Android 复用现有认证会话和订单读取服务，使用带 `scope=history` 的订单读取请求获取当前企业的已结算工单分页。客户端不得依靠本地状态文本把“当前工单”猜测为历史，也不得直接拼接其他企业 ID。

读取模型继续以服务端公司范围、会话 Bearer Token 和服务端状态为可信来源。每页响应必须被映射到现有订单摘要/详情领域模型；服务端未提供或格式不合法的字段使用安全显示回退，不能中断已缓存历史的展示。

### 2.2 企业隔离与缓存

历史摘要写入现有 Room 订单摘要表，并始终带 `companyId`。历史详情沿用现有加密详情缓存，读取时也只允许当前会话企业命中。缓存键不能由车牌、客户姓名或工单号单独组成。

首屏先显示当前企业的缓存结果，再在在线状态下刷新第一页。分页的游标、去重和“是否还有更多”状态只存在对应会话的 ViewModel 状态，不能跨账号或跨企业复用。登出、认证失效和无有效恢复仍复用已存在的客户数据清理路径。

### 2.3 离线与失败语义

离线时禁止发起历史读取请求，仅展示当前企业可解密的缓存数据，并显示“网络不可用，当前为只读模式”及可能非最新的同步提示。离线无缓存时显示诚实空状态和重新同步不可用提示，不伪造历史数据。

网络、5xx 和畸形响应不清除可用缓存，显示可重试的同步失败状态。401 必须执行共享会话失效及用户客户缓存清理；403/404 仅显示无权或不可访问结果，不泄露其他企业工单存在性。协程取消必须原样传播，不转换为错误提示或写入缓存。

### 2.4 界面与导航

“档案”标签根页包含：搜索输入、时间/状态筛选、历史卡片列表、初始加载、缓存陈旧、空结果、错误重试和加载更多状态。筛选在本地对已取得的历史摘要生效；服务器分页仍由 `scope=history` 和游标控制，不能把筛选条件当作访问控制。

点击列表卡片进入既有 `OrderDetail` 路由。历史详情仅显示信息和返回操作：编辑、普通状态推进、结算、返结算、作废及任何写入入口均不得出现在本批档案流中，即使用户是管理员或企业能力已开启。

## 3. 分批交付边界

本设计只覆盖阶段 4 第一批，按以下顺序实施：

1. 历史 scope 的 Android API、缓存读取/刷新、分页与错误映射；
2. 历史档案 ViewModel、筛选状态和只读 Compose 页面；
3. 根标签装配、历史详情写入入口屏蔽、Android UI 测试源码与无设备构建；
4. 后续独立设计/计划再处理客户车辆与保险档案读取，以及管理员非状态字段修正。

不新增 D1 migration，不修改 Cloudflare Pages 生产部署，不访问远程 D1，不改变 `EDIT_ORDER` 或 `ADVANCE_ORDER_STATUS` 等已发布能力开关。本批结束时生成 Debug APK 供真实手机验收，但不启动模拟器或运行 connected Android 测试。

## 4. 测试与验收

实施采用测试先行。至少锁定以下行为：

- `scope=history` 请求携带当前 Bearer Token、正确游标且不携带其他企业标识；
- 缓存只按当前企业展示，分页项稳定去重且不跨会话继承游标；
- 离线不发请求，网络/5xx/畸形响应保留可用缓存；
- 401 清理该会话客户数据并进入未认证状态；
- 员工和管理员均可浏览历史，但页面及详情没有任何历史写入入口；
- 搜索、筛选、加载更多、空状态、离线状态及重试具备 Compose 测试源码。

完成时运行 Node 全量测试、Android JVM 测试、Android 测试源码编译、Lint 与 Debug APK 构建；不启动 Android 模拟器。更新 `docs/android-client.md` 的真机清单、`docs/latest-handoff-prompt.md` 的进度，并提交推送当前分支。

## 5. 非目标和风险控制

- 不将网页端现有档案编辑逻辑直接复制到 Android；管理员字段修正需要单独的权限、冲突和审计设计。
- 不把本地缓存当作完整历史或访问控制依据；在线读取始终由服务端会话与企业范围裁决。
- 不自动重试、排队或恢复任何写入，因为本批没有写入命令。
- 不在日志、测试输出或 UI 提示中暴露 Token、手机号、VIN 或其他敏感详情。
